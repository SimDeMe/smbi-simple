# Gammelt design — backup

Forsiden blev 8. august 2026 lagt om til det nye design fra
`smbi-design/mockup-moderne.html` (nu `index.html` + `forside.css` + `forside.js`).

Denne mappe indeholder den gamle forside, som den så ud lige inden:

| Fil          | Hvad det er |
|--------------|-------------|
| `index.html` | Den gamle forside (Cormorant Garamond / Phosphor Icons) |
| `style.css`  | Kopi af det gamle stylesheet |
| `site.js`    | Kopi af det gamle script |

**Bemærk:** `style.css` og `site.js` ligger stadig i roden og bruges af
`biologi.html`, `geografi.html`, `born.html`, `contact.html` og `admin.html`.
Kopierne her er kun en øjebliksbillede-backup — ret i rodens filer, ikke i disse.

Skal den gamle forside tilbage: `cp backup-gammelt-design/index.html index.html`
